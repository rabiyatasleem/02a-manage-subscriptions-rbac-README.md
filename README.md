# AZ-104 Lab 2A — Manage Subscriptions and RBAC

## Objective

This lab provided hands-on experience with Azure management groups, Azure role-based access control (RBAC), custom roles, and role assignments.

## Azure Concepts

- Azure Management Groups
- Azure Subscriptions
- Azure RBAC
- Custom RBAC Roles
- Role Assignments
- Scope and Permissions

## What I Practiced

### 1. Management Groups

Created and worked with Azure Management Groups to understand how multiple Azure subscriptions can be organized into a hierarchy.

### 2. Custom RBAC Roles

Created a custom Azure RBAC role with specific permissions instead of using only built-in roles.

### 3. Role Assignments

Assigned an RBAC role to a security principal at the appropriate Azure scope.

## Key Learning

Azure RBAC controls who can access Azure resources, what they can do, and at which scope they can perform those actions.

The main RBAC concepts practiced in this lab were:

- Security Principal
- Role Definition
- Scope
- Role Assignment

## Real-World Use

RBAC is used to implement least-privilege access in Azure environments.

For example:

- Administrators can manage infrastructure.
- Developers can access application resources.
- Read-only users can inspect resources without modifying them.
